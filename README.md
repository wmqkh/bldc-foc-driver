# bldc-foc-driver
小白给自己的第一个长期项目，做一个电机驱动控制程序，备战春招
**基于 STM32 的无刷电机驱动与闭环控制**

- 硬件：三相桥驱动（IR2104S + N-MOS）+ 电流采样 + 栅极驱动 + 电源 + AS5600 磁编码器 + MCU 最小系统，自己画原理图、嘉立创打板、自己焊
- 软件：六步换相 → 正弦/SPWM →（有余力）FOC + 速度/位置闭环 + CAN/UART 通信 + Python 上位机
- 分两阶段降风险：**阶段一用现成开发板 + DRV8313 模块把算法跑通，阶段二再自画板打样

- 第一步，建立自己的仓库————已完成
